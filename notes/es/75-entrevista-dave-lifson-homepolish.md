# 75 - Entrevista: Dave Lifson (VP Producto, Homepolish)

## Su Background
Amazon (dev → PM en recomendaciones) → Etsy (primer Head of Product) → startup propia → General Assembly → Poppin → Homepolish

## Puntos Clave

### Que es Product Management?
> "Entendimiento profundo del cliente + entendimiento profundo del negocio → casar los dos para identificar oportunidades, priorizarlas, y disenar la solucion correcta para el momento correcto."

### Historia de Guerra: General Assembly "Front Row"
- Founders querian producto de suscripcion para escalar (sin problema de cliente — salio de un spreadsheet)
- Deadline de 3 meses → sin tiempo para investigacion
- Empaquetaron libreria de videos como suscripcion de $25/mes
- LTV nunca funciono. **Suscripcion es un modelo raro para educacion.**
- Leccion: "Como PM, deberia haber reconocido inmediatamente que no habia mencion del cliente."

### Como Entrar a PM Sin Experiencia

> "Muestra que entiendes el **proceso de PM** y puedes aplicarlo a diferentes situaciones."

El proceso: Identificar problema → Identificar cliente → Proponer solucion → Iterar → Validar supuestos

Formas de demostrarlo:
- **Hackathons** — aplica el proceso en 2 dias
- **Involucramiento interno** — desde marketing/analista, unirte a user research
- **Estructura tu CV** para resaltar cada paso — hiring managers veran que "lo entiendes" sin titulo PM

### Habilidades Tecnicas que Aprender

| Habilidad | Prioridad | Detalle |
|---|---|---|
| **Basicos de Agile** | Debe | User stories, sprint planning, retros |
| **Wireframing** | Debe | Lapiz y papel esta bien — comunica lo que esta en tu cabeza con dibujos |
| **Como funciona el internet** | Debe | Escribes URL → cuales son los 10-15 pasos antes de que aparezca la pagina? |
| **SQL** | Extra | PMs frecuentemente necesitan datos y no hay departamento de datos |
| **Lenguaje de programacion** | No necesario | Entiende arquitectura, no necesitas HTML/CSS/Ruby |

### Lo que Buscan los Hiring Managers
No el titulo de PM — sino evidencia de que has hecho los **pasos del proceso** en roles anteriores.
