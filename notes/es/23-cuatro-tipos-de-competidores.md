# 23 - Los Cuatro Tipos de Competidores

## Los Cuatro Tipos

| Tipo | Mismo problema? | Mismo cliente? | Prioridad |
|---|---|---|---|
| **Directo** | Si | Si | Tier 1 — mayor preocupacion |
| **Indirecto** | Si (diferente forma) | Diferente/superpuesto | Tier 2 |
| **Potencial** | No | Si/similar | Tier 3 |
| **Sustituto** | Misma necesidad core | No | Tier 4 |

## Metafora del Restaurante Italiano

| Tipo | Ejemplo |
|---|---|
| **Directo** | Restaurante italiano enfrente, mismo precio, tambien vende tortellini |
| **Indirecto** | Restaurante griego en otro barrio (la gente lo confunde con italiano) |
| **Potencial** | Tienda de abarrotes italiana — no sirve comida pero podria poner mesas |
| **Sustituto** | Pizza congelada DiGiorno — resuelve "hambre + quiero italiano" pero entrega totalmente diferente |

## Ejemplo GoPro

| Tipo | Competidores | Por que |
|---|---|---|
| **Directo** | Otras camaras de accion (mismo formato, misma audiencia) | Mismo problema, mismas personas |
| **Indirecto** | Sony Cyber-Shot, Canon PowerShot | Pueden grabar accion, pero para el partido de tenis del hijo, no paracaidismo |
| | Camara corporal Vievu | Mismo problema (camara pequena portatil), pero para policias |
| **Potencial** | Eyeshot 360 | Camara WiFi para vigilancia — misma experiencia tech, podria pivotar |
| **Sustituto** | Grip Opteka | Convierte cualquier camara en camara de accion — solucion completamente diferente |

## Como Organizar Tu Lista

```
TIER 1: Competidores Directos      ← mas preocupacion, debes ser competitivo
TIER 2: Competidores Indirectos    ← no perder demasiados clientes ante ellos
TIER 3: Competidores Potenciales   ← mantener en la periferia, que no puedan hacer facilmente lo tuyo
TIER 4: Competidores Sustitutos    ← asegurar que eres una alternativa viable
```

Reemplaza las categorias "Conocidos/Desconocidos" con estos 4 tiers en tu hoja de calculo.

## Buzzwords

| Termino | Definicion |
|---|---|
| **Competidor Directo** | Mismo problema, mismo cliente — usuarios eligen conscientemente entre tu y ellos |
| **Competidor Indirecto** | Mismo problema, diferente forma o diferente grupo de clientes |
| **Competidor Potencial** | Mismos clientes pero diferente problema — podrian pivotar a tu espacio |
| **Competidor Sustituto** | Resuelve la misma necesidad core de forma completamente diferente |
| **Competidor Periferico** | Otro nombre para Potencial — mantenlos en tu periferia |
| **Competitive Landscape** | La foto completa de todos los competidores organizados por tipo y prioridad |
