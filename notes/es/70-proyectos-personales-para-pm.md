# 70 - Proyectos Personales para Experiencia PM

## Cuando Hacer un Proyecto Personal

Cuando tienes **cero experiencia relevante** en tu trabajo actual.

## Que Hacer

| Opcion | Esfuerzo | Descripcion |
|---|---|---|
| **Redisenar un producto** | Bajo | Toma un producto que uses diario, describe como lo cambiarias para resolver mejor las necesidades |
| **Blog post / escrito** | Bajo-Med | Documenta tu proceso: problema → investigacion → solucion → wireframes |
| **Slide deck** | Medio | Presenta una propuesta de feature como si pitchearas a un equipo de producto |
| **Construir un prototipo** | Medio | Usa herramientas (Figma, Balsamiq) para crear wireframes/prototipos clickeables |
| **MVP completo** | Alto | Usa herramientas no-code (Bubble, Webflow) para construir y validar una idea |

## Que Documentar

1. **El problema de usuario** que identificaste
2. **Tu investigacion** (competidores, entrevistas, datos)
3. **Tu solucion propuesta** (wireframes, specs)
4. **Por que esta solucion** sobre las alternativas
5. **Metricas** que rastrearias para medir exito

## Ponlo en Algun Lugar Publico

- Sitio web/blog personal
- Articulo en Medium
- Repo en GitHub (como este)
- Portfolio deck
