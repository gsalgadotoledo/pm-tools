# 12 - Agile

## Que es Agile?

**Lean aplicado al desarrollo de software.** Un framework de project management para construir software iterativamente en lotes pequenos.

## Como Funciona

```
10 features en tu lista
        |
        v
Escoge las 2-5 mas importantes
        |
        v
Investigar -> Disenar -> Desarrollar -> Lanzar
        |
        v
Obtener feedback de usuarios PRIMERO
        |
        v
Luego decidir sobre las features restantes
```

## Lean vs Agile (Repaso)

| | Lean | Agile |
|---|---|---|
| **Que es** | Filosofia | Framework de software |
| **Alcance** | Cualquier negocio | Desarrollo de software |
| **Idea central** | No desperdiciar recursos | Construir en lotes pequenos, validar, repetir |
| **Relacion** | Agile ES Lean aplicado a software |

## Principio Clave

No construyas los 10 features. Construye los 2-5 mas importantes, lanza, obtiene feedback, **luego** decide que sigue.

## Buzzwords

| Termino | Definicion |
|---|---|
| **Agile** | Desarrollo iterativo de software en lotes pequenos para evitar desperdicio |
| **Iterative** | Construir en ciclos repetidos de disenar → desarrollar → lanzar → feedback |
