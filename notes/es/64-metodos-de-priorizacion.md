# 64 - Metodos de Priorizacion

## Priorizas Todo

No solo user stories — epics, iniciativas, campanas de marketing, lanzamientos. Las prioridades cambian constantemente.

## Tres Metodos Clasicos

### 1. Assumption Testing

| Dimension | Escala | Que significa |
|---|---|---|
| **Riesgo** (supuesto mas grande) | 1-10 | Que tan riesgoso es nuestro supuesto? |
| **Importancia** (impacto) | 1-10 | Que tan importante es construir esto? |
| **Score de prioridad** | Riesgo + Importancia | Ordenar del mas alto primero |

**Mejor para**: Stories dentro de un epic. "Si estamos equivocados, probarlo primero."

### 2. Metodo BUC (Business, User, Cost)

| Factor | Score (1-10) |
|---|---|
| **B**eneficios de negocio | Cuanto gana el negocio? |
| **U**ser beneficios | Cuanto gana el usuario? |
| **C**osto | Que tan caro/dificil es? |

**Formula**: `(Business + User) - Cost = Score de Prioridad`

### 3. Metodo MoSCoW

Imagina que no construyes **nada**. Que es lo peor que pasa?

| Categoria | Significado |
|---|---|
| **Must** | No podemos vivir sin esto — el negocio falla |
| **Should** | Importante pero no fatal si falta |
| **Could** | Bueno tener si hay tiempo |
| **Would** | Algun dia, si hay oportunidad |

**Regla**: Si un Must depende de otra cosa, esa dependencia tambien es Must.

## Mas Alla de los Metodos

| Factor | Como afecta prioridad |
|---|---|
| Movimientos de competidores | Lanzan algo → reaccionas |
| Nueva tecnologia disponible | Habilita algo antes imposible |
| Trabajo de otros equipos | Dependencias cambian tu timeline |
| Oportunidad de mercado / timing | La ventana puede cerrarse |
| Restricciones de presupuesto | No puedes hacer todo a la vez |
