# 22 - Como Encontrar Competidores

## Paso 0: Define Que Resuelves

Antes de buscar, responde dos preguntas:

1. **Que problema resuelve?** → ej: "Es dificil filmar secuencias de accion con camaras tradicionales"
2. **Para quien?** → ej: "Buscadores de adrenalina y videografos" (NO "mis usuarios" — se especifico)

## Paso 1: Capturar

Crea una hoja de calculo con dos categorias:

```
| A: Competidores         |
|-------------------------|
| CONOCIDOS               |
| 1. [competidor]         |
| 2. [competidor]         |
| DESCONOCIDOS            |
| 1. [competidor]         |
| 2. ...                  |
```

- **Conocidos**: competidores que ya conoces (si estas en una empresa, deberias saberlo — si no, busca "[tu empresa] versus")
- **Desconocidos**: los que estan escondidos — sin juicio, solo recopilar

> Truco rapido: Googlea "[TuEmpresa] versus" — el autocompletado revela tus principales competidores al instante.

## Paso 2: Tres Estrategias de Busqueda

### Estrategia 1: Canalizar la Queja del Usuario

Piensa: como describiria un usuario frustrado este problema?

| Busquedas ejemplo (GoPro) |
|---|
| "DSLR too big for action shots" |
| "keep breaking my camera skateboarding" |
| "camera too heavy for parachuting" |

**Que encontraras:**
1. Empresas usando ese mismo lenguaje en su marketing
2. Personas quejandose online → conversaciones → como otros resolvieron el problema
3. Conexiones relacionadas de Google

**Pro tip**: Usa `site:reddit.com`, `site:quora.com` para buscar en comunidades especificas.

### Estrategia 2: Describe Tu Producto Literalmente

Se un robot. Describe exactamente que hace.

| Busquedas ejemplo (GoPro) |
|---|
| "tiny camera fits to your head shoots video" |
| "compact camera designed for action" |
| "camera you can attach to your head that films" |

**Que encontraras:**
1. Empresas usando descripciones literales de features
2. **Anuncios arriba** — empresas pagando por estar ahi = probables competidores
3. Sugerencias relacionadas de Google

**Pro tip**: Usa `"comillas"` para busquedas de coincidencia exacta.

### Estrategia 3: Pitchealo en Una Oracion

Como pitchearias este producto?

| Busquedas ejemplo (GoPro) |
|---|
| "world's smallest 4K camera" |
| "best action camera for extreme sports" |

Se **especifico** — no "esta app te ahorra tiempo" sino "ahorra tiempo grabando notas de voz a Evernote."

---

## Resumen

```
Definir problema + para quien → Competidores conocidos → 3 estrategias para desconocidos:
  1. Lenguaje de queja del usuario + site:reddit/quora
  2. Descripcion literal del feature + revisar anuncios
  3. Pitch de una oracion
→ Agregar todo a tu hoja de calculo
```

## Buzzwords

| Termino | Definicion |
|---|---|
| **Market Intelligence** | Investigacion sobre competidores y condiciones del mercado |
| **Competidores Conocidos** | Competidores que tu y tu empresa ya conocen |
| **Competidores Desconocidos** | Competidores ocultos que descubres investigando |

## Herramientas

| Herramienta | Uso |
|---|---|
| **Google Autocomplete** | "[empresa] versus" revela competidores conocidos |
| **Google operador `site:`** | Buscar dentro de sitios especificos (reddit, quora) |
| **Google `"coincidencia exacta"`** | Comillas para resultados precisos |
| **Reddit / Quora / Yahoo Answers** | Comunidades donde usuarios discuten problemas y alternativas |
| **Google Ads (resultados top)** | Empresas pagando por aparecer = competidores autoseleccionados |
