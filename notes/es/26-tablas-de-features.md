# 26 - Tablas de Features

## Que es una Feature Table?

Un cuadro comparativo: **tu producto vs competidores** en multiples dimensiones.

```
|                    | Tu  | Competidor A | Competidor B | Competidor C |
|--------------------|-----|-------------|-------------|-------------|
| Feature 1          | ✓   | ✓           | ✗           | ✓           |
| Feature 2          | ✓   | ✗           | ✓           | ✗           |
| Feature 3          | ✗   | ✓           | ✓           | ✓           |
| Precio             | $99 | $149        | $79         | $129        |
| Plataforma         | All | Web only    | iOS only    | All         |
```

- **Eje X (columnas)**: Tu producto + competidores
- **Eje Y (filas)**: Dimensiones/features a comparar

## Por Que Hacer Feature Tables?

| Razon | Detalle |
|---|---|
| **Saber que es cutting edge** | Antes de lanzar, saber que ya existe |
| **Visual rapido** | Todo tu equipo puede ver instantaneamente: somos competitivos? |
| **No puedes rastrear mentalmente** | Demasiados competidores, demasiados features (GoPro tiene 50+ competidores) |
| **Evitar lanzar algo peor** | Si tu producto es peor que lo que ya existe, probablemente fallaras |

## Cuando Usarlas

- Antes de generar ideas de producto
- Antes de lanzar productos
- Como documento vivo de referencia para tu equipo

> No *tienes* que hacerlas en el trabajo, pero saber como es un **activo inmensamente valioso**.

---

## Buzzwords

| Termino | Definicion |
|---|---|
| **Feature Table** | Cuadro comparativo de tu producto vs competidores en multiples dimensiones |
| **Feature Parity** | Cuando tu producto iguala a los competidores en un feature especifico |
| **Competitive Gap** | Features que los competidores tienen y tu no |
