# 03 - Tipos de Product Managers

## Los Tres Tipos Principales

### 1. Internal Product Manager (PM Interno)

- Parte de un equipo de "internal tools" (herramientas internas).
- Construye herramientas **para personas dentro de su propia empresa**, no para usuarios externos.
- Ejemplo: software que el equipo de soporte usa para resetear passwords o cambiar info de cuentas.
- **Stakeholders**: empleados internos que usan esas herramientas.

### 2. Business-to-Business (B2B) Product Manager

- Tambien llamado **SaaS Product Manager** (Software as a Service).
- Construye productos cuyos **clientes son otras empresas** (ej: Oracle, Salesforce).
- Trabaja de cerca con **equipos de ventas** para asegurar que el producto cumple los requisitos de negocio.
- **Stakeholders**: las empresas que compran el producto + equipos de ventas internos.

### 3. Business-to-Consumer (B2C) Product Manager

- El tipo mas comun.
- Construye productos para el **publico general** (ej: Facebook, Twitter, Instagram, SoundCloud).
- Requiere amplio rango de habilidades, **vision** y **creatividad**.
- Se enfoca en maximizar **metricas de uso** — nadie te dice exactamente que construir.
- Pasa mucho tiempo hablando con usuarios, creando prototipos y analizando datos.
- **Stakeholders**: millones de usuarios finales.

---

## B2B vs B2C — Diferencia Clave

| | B2B | B2C |
|---|---|---|
| **Quien decide que construir?** | Ventas dice "ganaremos $5M si construimos X" | Nadie puede predecir exactamente que construir |
| **Metodo de validacion** | Requisitos de negocio de clientes | User testing, prototipos, analisis de datos |
| **Proximidad al stakeholder** | Contacto directo via ventas | Indirecto — millones de usuarios anonimos |

---

## Buzzwords

| Termino | Definicion |
|---|---|
| **Stakeholders** | Personas para quienes construyes, o que tienen input en lo que construyes |
| **Internal Tools** | Software construido para uso interno de la empresa |
| **B2B** | Business-to-Business — vender productos a otras empresas |
| **B2C** | Business-to-Consumer — construir productos para el publico general |
| **SaaS** | Software as a Service — software entregado como servicio por suscripcion |

---

## Herramientas y Tecnicas

| Herramienta/Tecnica | Contexto |
|---|---|
| **Prototyping** | PMs B2C crean multiples prototipos para validar ideas antes de construir |
| **User Testing** | Probar el producto directamente con usuarios reales para obtener feedback |
| **A/B Testing** | Comparar dos versiones de un feature para ver cual funciona mejor |
| **Analisis de Datos/Metricas** | Usar datos cuantitativos para decidir que construir — mas usuarios = testing mas poderoso |
