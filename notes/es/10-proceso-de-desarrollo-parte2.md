# 10 - Proceso de Desarrollo del Producto (Parte 2)

## Las 7 Fases (Completas)

```
Concebir -> Planear -> Desarrollar -> Iterar -> Lanzar -> Estado Estable -> Mantener/Matar
                                                [-------- esta nota --------]
```

## Fase 5: Lanzar

- Trabajar con equipos de **marketing**, **legal**, **PR** y **ventas**
- **Posicionar** el producto para lanzamiento publico
- Lanzar al publico y observar la reaccion

## Fase 6: Estado Estable

- Recopilar **metricas** de uso y compras
- **Analizar** y **optimizar** metricas para maximo ROI
- Marketing sigue promocionando, ventas sigue vendiendo
- Evaluar: debemos seguir con esto?

## Fase 7: Mantener o Matar

Dos preguntas a responder:

| Pregunta | Si SI | Si NO |
|---|---|---|
| Se paga solo? (ROI) | Mantener | Considerar matar |
| Encaja con la vision de la empresa? | Mantener | Matar aunque sea rentable |
| Seguimos siendo competitivos? | Mantener | Considerar matar |

**Razones para matar un producto:**
- Revenue pobre / no se paga solo
- Ya no encaja con la vision o direccion de la empresa
- El mercado cambio, ya no es competitivo
- Costo de mantenimiento muy alto vs retorno

**Al matar un producto → Sunsetting:**
- Transicion lenta al fin de vida
- Comunicar a los usuarios que esta pasando
- Crear un **plan de fin de vida** (ej: dejar que usuarios exporten/respalden sus datos)

---

## Resumen de las 7 Fases

| # | Fase | Actividad Clave |
|---|---|---|
| 1 | **Concebir** | Recopilar problemas de usuarios, brainstorming de soluciones |
| 2 | **Planear** | Investigacion de mercado, business case, entrevistas, roadmap |
| 3 | **Desarrollar** | Timelines, specs, user stories, estimaciones |
| 4 | **Iterar** | MVP, testing alpha/beta, validar supuestos |
| 5 | **Lanzar** | Coordinar con marketing/legal/PR/ventas, salir al publico |
| 6 | **Estado Estable** | Recopilar metricas, optimizar, evaluar viabilidad |
| 7 | **Mantener/Matar** | Seguir invirtiendo o hacer sunset del producto |

---

## Buzzwords

| Termino | Definicion |
|---|---|
| **Sunsetting** | El proceso de cerrar lentamente un producto |
| **End-of-Life (EOL)** | El punto donde un producto ya no tiene soporte ni esta disponible |
| **ROI** | Return on Investment — el producto gana mas de lo que cuesta? |
| **Positioning** | Como presentas el producto al mercado vs competidores |
