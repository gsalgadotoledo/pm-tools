# 45 - Tipos de MVP (Parte 2): Video Explainer y Fake Landing Page

## 4. Explainer MVP

Simular un video mostrando tu producto funcionando — antes de construirlo.

### Dos Estilos

| Estilo | Como funciona | Ejemplo |
|---|---|---|
| **Tutorial** | Screencast pretendiendo usar el feature. Editar para que paginas estaticas parezcan conectadas | **Dropbox** — founder hizo video demo falso en YouTube, tuvo respuesta enorme, luego lo construyo |
| **Ventas/Promo** | Video animado o talking-head pitcheando el producto con CGI/animaciones | **Framework** — pitcheo nuevos features con animaciones, features no existian, "registrate para notificacion de lanzamiento" |

**Por que funciona**: Productos reales tienen videos promo/tutorial. Los usuarios no notan la diferencia.

## 5. Fake Landing Page / Pitch Experiment MVP

Una pagina que pitchea tu producto + call to action (registrate, compra, etc.).

### Terminos Clave

| Termino | Definicion |
|---|---|
| **Landing Page** | Pagina web unica y enfocada — usuario solo puede hacer una cosa (registrarse, comprar, etc.) |
| **Pitch Experiment** | Experimento online donde pitcheas un producto/feature y observas reacciones |

### Por Que Landing Pages Funcionan como MVPs

- Completamente enfocadas — usuario no puede ignorar el pitch
- Dirigir trafico via ads, email, push notifications
- **Gold standard** para tests MVP de emprendedores

### Ejemplos

| Empresa | Que hicieron |
|---|---|
| **Buffer** | Creo pagina falsa pitcheando su servicio de scheduling de social media. Dirigio trafico. Observo con que interactuaba la gente para armar el producto como un rompecabezas |
| **Basecamp** (37 Signals) | Usa landing pages para cada side project nuevo — "Esto es lo que hace, aqui esta por que es increible, compralo o registrate" |
