# 50 - Wireframe vs Mockup vs Prototipo

## La Escala de Fidelidad

```
Baja Fidelidad ←――――――――――――――――――――――――――――→ Alta Fidelidad
  WIREFRAME          MOCKUP              PROTOTIPO
  Estructura         Visuales            Usabilidad
```

## Comparacion

| | Wireframe | Mockup | Prototipo |
|---|---|---|---|
| **Enfoque** | Estructura, layout, organizacion | Colores, tipografia, estilo | Usabilidad, interaccion |
| **Fidelidad** | Baja | Media | Alta |
| **Interactividad** | Ninguna | Ninguna (estatico) | Si — hotspots clickeables, gestos basicos |
| **Quien lo hace** | PM + Disenador | Disenador | Disenador + PM |
| **Analogia** | Plano | Pintura | Modelo funcional |
| **Tambien llamado** | Esqueleto | Display estatico | Mockup interactivo |

## No Los Confundas

- **Wireframe** = estructura → "Donde va cada cosa?"
- **Mockup** = visuales → "Como se ve?"
- **Prototipo** = interaccion → "Como se siente usarlo?"

## Herramientas por Fase

### Herramientas de Wireframing
| Herramienta | Notas |
|---|---|
| **Balsamiq** | Mas popular para baja-fi, estilo sketch, divertido |
| **Axure** | Enterprise, colaborativo, maneja las 3 fases |
| **OmniGraffle** | Aun se usa, algo tosco |
| **HotGloo** | Solo browser |
| **POP** | Convertir sketches en papel a wireframes digitales |

### Herramientas de Mockup
| Herramienta | Notas |
|---|---|
| **Photoshop** | Mas comun, poderoso pero tosco para mockups |
| **Sketch** | Ganando popularidad, mas rapido que Photoshop |
| **Illustrator** | Basado en vectores, algunos disenadores lo prefieren |
| **Axure** | Tiene libreria de imagenes + templates para convertir wireframes a mockups |
| **UXPin** | Flujo wireframe-a-mockup |

### Herramientas de Prototipado
| Herramienta | Notas |
|---|---|
| **Keynote** | + templates Keynotopia — enlazar slides, cargar en telefono/browser |
| **POP** | Agregar interacciones a sketches de wireframe |
| **Axure** | Pipeline completo wireframe→mockup→prototipo |
| **Proto.io** | Enfocado solo en apps moviles |
| **InVision** | Mejor para prototipado — importar mockups, agregar multiples capas de interaccion |

---

> **Ver [Herramientas 2026](tools-2026-actualizacion.md)** — InVision murio, Adobe XD descontinuado, Figma domina las 3 fases. POP muerto. Nuevas herramientas AI (Figma Make, Uizard, Lovable) generan prototipos desde texto.
