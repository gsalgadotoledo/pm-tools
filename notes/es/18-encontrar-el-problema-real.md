# 18 - Encontrar el Problema Real Detras de las Solicitudes

## La Mentalidad del PM

No construyas lo que la gente pide. Encuentra el **problema real** detras de la solicitud.

> "Encuentra una solucion a un problema, en vez de intentar encajar un problema a una solucion."

## El Ejemplo de la Toalla

```
Amigo en la lluvia: "Dame una toalla"
    → Solicitud: toalla (arreglo del sintoma)
    → Problema real: esta en la lluvia
    → Solucion real: sacarlo de la lluvia
```

## Dos Preguntas para Cada Solicitud

1. **"Esto resuelve un problema real?"**
2. **"Si hacemos esto exactamente como lo piden, tendra efectos secundarios no deseados?"**

## Ejemplo: Filtro de Retweets en Twitter

| | |
|---|---|
| **Solicitud** | Dejar que usuarios filtren retweets del timeline |
| **Parece razonable?** | Si — el timeline esta desordenado |
| **Efecto secundario** | 20-40% no ven retweets → menos gente retweetea → Twitter pierde senal de que es popular → dana el producto core |

## Ejemplo: CMS de E-commerce

| | |
|---|---|
| **Solicitud** | Marketing necesita poner/quitar mensajes rapidos en paginas de producto |
| **Por que?** | Merchandising le dijo a marketing que lo pidiera |
| **Por que?** | La pagina de shorts tenia tallas/fotos confusas → usuarios confundidos → se van |
| **Por que?** | Querian que usuarios llamaran a soporte para aclarar |
| **Problema real** | La pagina era confusa |
| **Solucion real** | Redisenar la pagina para que sea clara → no se necesitan mensajes ni llamadas a soporte |

## La Tecnica de "Preguntar Por Que 3 Veces"

```
Alguien te pide construir X
    → "Por que necesitas esto?" → respuesta superficial
    → "Por que?" → mas cercano a la verdad
    → "Por que?" → pain point real revelado
```

Simple pero **la mayoria de la gente lo omite.**

## Buzzwords

| Termino | Definicion |
|---|---|
| **Pain Point** | El problema subyacente real que un usuario experimenta |
| **Sintoma vs Problema** | La solicitud es frecuentemente un sintoma; tu trabajo es encontrar la causa raiz |
| **Efectos Secundarios No Deseados** | Consecuencias negativas de construir exactamente lo que pidieron |
| **Los 3 Por Que** | Tecnica: preguntar "por que?" al menos 3 veces para llegar al problema real |

## Frameworks

| Framework | Que es |
|---|---|
| **Los 3 Por Que** | Preguntar "por que?" al menos 3 veces en cualquier solicitud para descubrir el pain point real |
