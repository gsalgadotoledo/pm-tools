# 47 - Email MVP: Detalle

## Mejor Para

Organizaciones pequenas con **baja ansiedad de marca**.

## Pros y Contras

| Pros | Contras |
|---|---|
| Muy rapido de ejecutar | Puede verse descuidado |
| Limitar grupo de prueba facilmente | No es estandar pedir comprar via email |
| Segmentar usuarios por stats de uso/perfil | Riesgo de danar tu marca si el tono no coincide |
| Barato — no necesita tiempo de dev | |
| Cualquiera puede hacerlo | |

## Tips para el Exito

| # | Tip |
|---|---|
| **1** | **Conoce la tolerancia de tu audiencia** — marca de lujo vs outlet tienen umbrales diferentes. AppSumo lo logra porque venden flash deals a emprendedores acostumbrados a productos beta |
| **2** | **Iguala el valor de produccion** — usa los mismos templates, diseno, imagenes y tono de tus campanas normales. Usa herramientas como **Canva** para imagenes rapidas |
| **3** | **Combina con otra tecnica MVP** — email solo es cutre. Agrega link a landing page, u ofrece programa beta concierge en el email |

## Combinaciones

| Email + | Como funciona |
|---|---|
| **Landing Page** | Pitch en email → link a landing page para mas info |
| **Concierge** | Pedir que respondan con interes → guiarlos manualmente en un beta |
| **Shadow Button** | Mencionar el feature → link al producto donde vive el shadow button |
