# 52 - Practica de Sketching: App Mobile de Groceries

## El Proceso en Accion

### Idea de app: Delivery de groceries mobile (ordenar de tiendas cercanas)

### Pantalla 1: Login / Splash Page

```
┌─────────────────┐
│   [Logo]         │
│                  │
│   Nombre App     │
│                  │
│ [Login Facebook] │
│ [Login Email]    │
│                  │
└─────────────────┘
        ↓ (despues de login)
```

### Pantalla 2: Pantalla Principal

**Punto de la pagina**: Dejar que usuarios encuentren una tienda y empiecen a escoger items.

**Funciones**: Ver items visualmente, ver precios, buscar.

```
┌─────────────────┐
│ [Elegir Tienda ▼]│
│ ┌──────────────┐ │
│ │ Nombre Tienda│ │
│ └──────────────┘ │
│ [🔍 Buscar... ] │
│ ┌────┐ ┌────┐   │
│ │ 🍎 │ │ 🍌 │   │
│ │ $$  │ │ $$  │   │
│ ├────┤ ├────┤   │
│ │ 🍇 │ │ 🍊 │   │
│ │ $$  │ │ $$  │   │
│ └────┘ └────┘   │
│ [nav] [nav] [nav]│
└─────────────────┘
        ↓ (tap en item)
```

### Pantalla 3: Pagina de Detalle

**Punto de la pagina**: Mostrar info del item para que puedan comprarlo.

**Funciones**: Ver imagen, leer descripcion, seleccionar cantidad, comprar.

```
┌─────────────────┐
│                  │
│    [Big 🍎]      │
│                  │
│ ~~descripcion~~  │
│ ~~texto aqui~~~  │
│                  │
│  Cant: [- 1 +]  │
│                  │
│ [BOTON COMPRAR]  │
│                  │
└─────────────────┘
```

## Recordatorios Clave

- **Conecta pantallas con flechas** — muestra el flujo (izquierda a derecha)
- **Etiqueta interacciones** — escribe que boton lleva a donde
- **Empieza con lo facil** — barras de nav, pantallas de login activan la creatividad
- **Funcion, no forma** — nadie juzga tus habilidades de dibujo
- **Esto es rapido** — se supone que sea rapido y desechable
