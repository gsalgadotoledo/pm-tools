# 58 - Framework AARRR Metricas Pirata

## Que es AARRR?

Un framework de 5 pasos de **Dave McClure** (500 Startups). Popular en Silicon Valley, especialmente para SaaS y startups buscando inversion.

## Los 5 Pasos (Funnel)

```
Adquisicion → Activacion → Retencion → Referencia → Revenue
     A             A           R           R          R
```

| Paso | Que significa | Metrica ejemplo |
|---|---|---|
| **Adquisicion** | Usuario llego (visito sitio, descargo app) | Nuevos visitantes/mes, descargas de app |
| **Activacion** | Usuario se registro e hizo una accion clave | % descargas que crean cuenta + agregan foto de perfil |
| **Retencion** | Usuario regresa repetidamente | % usuarios activos mes a mes |
| **Referencia** | Usuario refiere a otros (suficientemente contento para compartir) | Invitaciones enviadas/usuario, tasa de conversion de referidos |
| **Revenue** | Usuario genera dinero | Revenue/usuario, conversion a suscripcion, revenue por ads/usuario |

## Como Cada Paso Alimenta al Siguiente

```
Muchos adquiridos → Algunos se activan → Menos se retienen → Aun menos refieren → Revenue de los mejores
```

Optimizar metricas en cada paso para maximizar el fondo del funnel.

## Ejemplos de Optimizacion de Retencion

- Push notification si el usuario no ha entrado en 1-2 semanas
- Campanas de email drip (semanal → bisemanal → mensual)

## Ejemplos de Optimizacion de Referencia

- Dropbox: invita un amigo → recibe almacenamiento gratis
- Uber: comparte un codigo → ambos reciben viaje gratis

## HEART vs AARRR

| | HEART | AARRR |
|---|---|---|
| **Creador** | Kerry Rodden (Google) | Dave McClure (500 Startups) |
| **Enfoque** | Experiencia de producto + felicidad | Funnel de crecimiento + revenue |
| **Incluye felicidad?** | Si (H) | No (implicito en Referencia) |
| **Incluye engagement?** | Si (E) | No (implicito en Retencion) |
| **Incluye exito de tarea?** | Si (T) | No |
| **Mejor para** | PMs en empresas establecidas | Startups, SaaS, buscando inversion |
