# 41 - Criterio Minimo de Exito (MVP Paso 4)

## Tres Resultados de Cualquier Test MVP

| Resultado | Que hacer |
|---|---|
| **1. Categoricamente falso** | Descartarlo — decision facil |
| **2. Claramente verdadero** | Proceder — decision facil |
| **3. En algun punto intermedio** | **90% del tiempo estaras aqui** — por eso necesitas MCS |

## Por Que Necesitas MCS (Minimum Criteria for Success)

- Sin el, no puedes saber si **pasaste o fallaste**
- Una hipotesis validada ≠ senal clara para proceder (puede estar validada pero no vale la inversion)
- Da a los experimentos **claridad y significado** — no "mejorar cosas" sino "mejorar cosas en X cantidad"

## El Calculo de Dos Lados

```
| COSTO (izquierda)        | RECOMPENSA ESPERADA (derecha) |
|--------------------------|-------------------------------|
| Tiempo de desarrolladores| Mejora de metrica objetivo    |
| Tu tiempo + equipo       | Tasa de conversion            |
| Dinero gastado           | Engagement (likes, shares)    |
| Costos de promocion/ads  | Porcentaje de sign-up         |
| Costo de oportunidad     | Revenue por cliente           |
| Riesgo de marca          | Tasa de reacciones positivas  |
| Desplazamiento de otras  |                               |
| iniciativas              |                               |
```

## Lado Derecho: Metricas de Recompensa Esperada

| Para productos nuevos | Para productos existentes |
|---|---|
| % de personas registrandose | Tiempo en pagina |
| Tasa de conversion | Acciones por sesion |
| Open rate (email) | Numero de shares/likes |
| % reacciones positivas | Revenue por usuario |
| Revenue por cliente | Retencion/churn |

> Cada metrica debe estar **directa o indirectamente relacionada** a una metrica crucial del negocio. Si no, estas inflando **metricas de vanidad**.

## Lado Izquierdo: Costos a Considerar

- **Tiempo** de developers/disenadores/PM (tiempo = dinero)
- **Dinero** para herramientas, contractors, promocion
- **Costo de oportunidad** — si persigues X y fallas, pudiste haber hecho Y
- **Desplazamiento** — el espacio de email/ad que usaste pudo ir a otro lado
- **Riesgo de marca** — especialmente en empresas grandes
- **Moral** — impacto en el equipo de perseguir y fallar

## Considerar Tamano de la Org

| Org pequena | Org grande |
|---|---|
| Experimentos scrappy OK | Necesitan algo mas robusto — ponen su nombre en ello |
| Menor riesgo de marca | Mayores consideraciones de marca |
| Recursos mas limitados | Mas recursos pero mayor costo de oportunidad |
