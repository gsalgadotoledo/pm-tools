# 05 - Product vs Project Management

**No** son lo mismo. Pero project management es una **habilidad** que todo PM necesita.

## Diferencia Principal

| | Product Manager | Project Manager |
|---|---|---|
| **Responsable de** | Lograr una **meta/metrica** | Completar un **proyecto** |
| **Exito significa** | Alcanzar el KPI (ej: +10% conversion) | Entregar a **tiempo** y en **presupuesto** |
| **Como lograrlo** | Tu decides — investigar, experimentar, iterar | Plan predefinido — ejecutarlo |
| **Enfoque** | Flexible, experimental | Rigido, estructurado |
| **Tolerancia al riesgo** | Alta — probar diferentes enfoques | Baja — seguir el plan |

## Ejemplos

| Escenario | Quien lidera? | Por que? |
|---|---|---|
| Aumentar conversion de checkout 10% | **Product Manager** | Basado en meta, metodo abierto |
| Construir un rascacielos a tiempo y presupuesto | **Project Manager** | Alcance definido, sin experimentar |
| Fusionar dos plataformas tech post-adquisicion | **Project Manager** | Resultado conocido, muchas piezas moviles |
| Agencia construye software segun spec del cliente | **Project Manager** | Requisitos definidos, ejecutar en presupuesto |
| Decidir que feature construir para usuarios | **Product Manager** | Requiere investigacion, sin respuesta predefinida |

## Donde se Cruzan

Los PMs cambian a "modo ejecucion" al pasar de descubrimiento a desarrollo — ahi entran las **habilidades de project management** (timelines, seguimiento, entrega).

---

## Buzzwords

| Termino | Definicion |
|---|---|
| **KPI** | Key Performance Indicator — la metrica que define el exito |
| **Conversion Rate** | % de usuarios que completan una accion deseada (ej: checkout) |
| **Execution Mode** | Fase donde el equipo construye lo decidido — foco en entrega |
| **Requirements** | Especificaciones definidas de lo que se debe construir |
