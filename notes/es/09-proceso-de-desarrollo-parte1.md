# 09 - Proceso de Desarrollo del Producto (Parte 1)

## Las 7 Fases

```
Concebir -> Planear -> Desarrollar -> Iterar -> Lanzar -> Estado Estable -> Mantener/Matar
[--- esta nota ---]                             [--- siguiente nota ---]
```

## Fase 1: Concebir

- Recopilar **problemas de usuarios**
- **Brainstorming** de soluciones
- Identificar **areas de enfoque**
- Mayor fuente de ideas: **empleados dentro de la empresa**

## Fase 2: Planear

- **Investigacion de mercado** sobre las ideas
- Evaluar el **business case** — esto va a generar dinero?
- **Entrevistas con clientes** — la gente realmente tiene este problema?
- **Roadmap** — que construir, cuanto tiempo, milestones de features

## Fase 3: Desarrollar

- Crear **timelines**
- Escribir **user stories** y **specs**
- Obtener **estimaciones** de desarrollo sobre features especificos
- Los requisitos deben estar **fijos** hasta la validacion del MVP

## Fase 4: Iterar

- Terminar el **MVP** (Minimum Viable Product) — el prototipo temprano
- Obtener **feedback temprano** de usuarios
- **Probar supuestos** de la idea original
- No esperar hasta terminar todo — probar lo antes posible
- Usar programas **Alpha** y **Beta** para validar direccion

---

## Buzzwords

| Termino | Definicion |
|---|---|
| **Product Development Process** | Las 7 fases de un producto desde la idea hasta el fin de vida |
| **MVP** | Minimum Viable Product — version mas simple para validar con usuarios |
| **Business Case** | Justificacion para construir algo — generara dinero/impacto? |
| **Customer Interviews** | Hablar con usuarios potenciales para validar si un problema existe |
| **Alpha** | Version de prueba interna, antes de beta |
| **Beta** | Version pre-release probada por un grupo limitado de usuarios reales |
