# 72 - Tus Primeros Dias como PM

> Nuevo capitulo: Sobresalir en el Rol de PM

PM tiene uno de los **tiempos de ramp-up mas largos** — necesitas entender la historia, metas y retos de cada equipo.

## 6 Tips para Tus Primeras Semanas

| # | Tip | Que hacer |
|---|---|---|
| **1** | **Agenda 1-on-1s con todos** | Reunirte con lideres de cada equipo. Preguntar: metas? retos? Tomar notas |
| **2** | **Reunirte con el lead de ingenieria** | Entender: arquitectura, bases de datos, lenguajes, retos tecnicos mas grandes, como se almacenan datos |
| **3** | **Empezar a hablar con usuarios** | Unirte a llamadas de ventas, sentarte con servicio al cliente, buscar en Twitter/Reddit que dice la gente |
| **4** | **Leer cada documento interno** | Epic specs pasados, releases moviles, decks de ventas, presentaciones internas → vista historica del producto |
| **5** | **Revisar los datos** | Reunirte con data science/analistas. Que metricas existen? Que tracking falta? |
| **6** | **Reunirte con el jefe (Head of Product / CEO)** | Preguntar: expectativas del rol, metricas a optimizar, mayores miedos para el proximo ano, competidores, mejoras de proceso |

## Por Que Importa Cada Paso

| Paso | Que te da |
|---|---|
| 1-on-1s | Mapa de la org — quien hace que, donde esta la friccion |
| Deep dive de ingenieria | Saber que es posible antes de proponer features |
| Hablar con usuarios | Tus propias conclusiones, no supuestos heredados |
| Leer docs | Historia de decisiones — evitar repetir errores |
| Revisar datos | Saber que puedes medir y que falta |
| Reunion con jefe | Alineacion de expectativas desde el dia uno |
