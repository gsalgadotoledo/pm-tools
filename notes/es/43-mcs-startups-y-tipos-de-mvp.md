# 43 - MCS para Startups e Introduccion a Tipos de MVP

## MCS Pre-Producto: Como Difiere

| | Producto Establecido (PM) | Pre-Producto (Startup) |
|---|---|---|
| **Metricas que importan** | Minutos consumidos promedio, retencion, engagement | **Metricas de validacion** — este producto merece existir? |
| **Lado derecho (recompensa)** | Cambio de comportamiento, mejora de metrica | Senales de **interes real** |
| **Costo de oportunidad** | Importante — podrias construir otra cosa | Menos importante — si falla, estaras buscando trabajo |
| **Enfoque economico** | ROI del feature | Viabilidad economica general (LTV, margenes brutos) |

## Metricas de Validacion (Startups)

| Metrica | Que senala |
|---|---|
| % de personas que se registran | Interes en el producto |
| % de personas que comparten tu post | Entusiasmo organico |
| Precio promedio de compra | Disposicion a pagar |
| Open rate de email | Engagement con tu mensaje |
| Tasa de conversion | Pasar de interes a accion |
| Lifetime Value (LTV) | Viabilidad economica a largo plazo |
| Margenes brutos | Es sostenible como negocio? |

## Transicion: Ahora Elige Tu Tipo de MVP

En este punto tienes:
1. Set problema/solucion
2. Supuestos identificados y rankeados
3. Hipotesis construidas
4. Criterio minimo de exito definido

**Siguiente**: Elegir el formato correcto de experimento MVP. La pregunta clave:

> Cuanto necesitas "fingir" que tu producto existe para obtener los datos que necesitas?

La respuesta determina que tipo de MVP usar.
