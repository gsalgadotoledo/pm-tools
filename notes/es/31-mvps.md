# 31 - MVPs (Minimum Viable Product)

> Nuevo capitulo: MVPs

## Que es un MVP?

La **cantidad minima** de un producto propuesto que puedes construir para obtener **feedback real** sobre si los usuarios estan realmente interesados.

> MVP es un **proceso** (un experimento), no un prototipo.

## El Experimento MVP

```
Supuesto → Hipotesis → Criterio minimo de exito → Probar → Aprender
```

| Concepto | Definicion |
|---|---|
| **Validated Learning** | Aprender de clientes en un entorno de prueba sin sesgo donde actuan naturalmente |
| **Learning** | Cualquier otra cosa — no disenado como experimento, no se puede confiar en resultados |

## La Metafora del Camino

```
Estas en una bifurcacion con 3 caminos. Los del pueblo DICEN que saben la ruta.
    → No confies en opiniones (subjetivas, cualitativas)
    → Camina por cada sendero solo lo suficiente para ver si es correcto
    → Minimo esfuerzo para validar direccion = MVP
```

## Ejemplo Clasico: Zappos

| Enfoque tradicional | Enfoque MVP (lo que hizo Zappos) |
|---|---|
| Construir sitio web elegante | Hacer un sitio web basico |
| Comprar inventario | Tomar fotos en una zapateria local |
| Contratar programadores | Cuando alguien compraba, comprar fisicamente el zapato y enviarlo |
| Esperar que la gente quiera | **Validaron** que la gente compraria zapatos online |

## Por Que MVPs?

| Razon | Detalle |
|---|---|
| **Validacion de ideas** | Saber si la gente lo quiere ANTES de construirlo completo |
| **Mitigacion de riesgo** | Mas barato probar con un Google Form que construir una plataforma completa |
| **Velocidad** | Fallar rapido → mas experimentos → encontrar lo que funciona mas rapido |
| **Ahorrar recursos** | Tiempo, dinero, costo de oportunidad |

## Error Comun

MVP ≠ prototipo o version basica de tu producto. MVP = **lo que sea necesario para validar la idea**, que frecuentemente significa **construir casi nada**.

## El Mantra de "Fail Fast"

```
Experimentos MVP mas rapidos → Mas experimentos en mismo tiempo → Mas datos → Mejores decisiones
```

## Buzzwords

| Termino | Definicion |
|---|---|
| **MVP** | Minimum Viable Product — lo minimo para validar una idea |
| **Validated Learning** | Aprender de pruebas con clientes sin sesgo en condiciones naturales |
| **Fail Fast** | Correr experimentos rapidos para que los fracasos ocurran temprano y barato |
| **Hypothesis** | Tu supuesto sobre lo que los usuarios quieren, a ser probado |
