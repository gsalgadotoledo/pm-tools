# 44 - Tipos de MVP (Parte 1): Email, Shadow Button, 404/Coming Soon

## El Principio

> Presentar algo que **implique que tu producto es real**. El grado de simulacion determina que tipo de MVP usar.

Validated learning requiere que los usuarios **no sepan que estan siendo probados**.

## Tipos de MVP (Orden: Mas Falso → Menos Falso)

### 1. Email MVP

| Aspecto | Detalle |
|---|---|
| **Que es** | Enviar email a un segmento de usuarios pitcheando un nuevo feature/producto como si fuera real |
| **Recursos necesarios** | Cliente de email, lista de usuarios, copywriting |
| **Dificultad** | La mas baja |
| **Mejor para** | Empresas establecidas (tienen lista de email) Y founders tempranos (recopilar emails objetivo) |
| **Ejemplo** | AppSumo prueba nuevos productos enviando "ven y registrate" o incluso poniendo boton de compra antes de que el producto exista |

### 2. Shadow Button MVP

| Aspecto | Detalle |
|---|---|
| **Que es** | Agregar un boton en tu producto para un feature que aun no existe. Rastrear clicks. |
| **Que pasa al hacer click** | Cualquiera de: nada (parece roto) o mensaje "Disculpa, coming soon" |
| **Recursos necesarios** | Pequeno esfuerzo de dev para agregar boton + tracking |
| **Mejor para** | PMs triageando features nice-to-have |
| **Ejemplo** | Startup decidiendo entre opciones de login (Email, Facebook, Twitter, Google, LinkedIn) — poner botones falsos, ver cuales la gente realmente clickea |

### 3. Pagina 404 / Pagina Coming Soon

| Aspecto | Detalle |
|---|---|
| **Que es** | Linkear a una pagina que muestra 404 o "Coming Soon — registra tu interes" |
| **Recursos necesarios** | Landing page + formulario de registro |
| **Mejor para** | Probar demanda para productos o categorias completamente nuevas |
| **Ejemplo: Amazon** | Usa paginas 404/coming-soon **diariamente** para probar demanda de nuevas categorias |
| **Ejemplo: Oculus Rift** | Lanzo con solo un prototipo crudo + pagina de pre-orden = MVP |
| **Ejemplo: Kickstarter** | Las paginas de pre-orden son esencialmente MVPs coming-soon |

---

## Resumen Hasta Ahora

| Tipo de MVP | Esfuerzo | Nivel de Simulacion | Quien lo usa |
|---|---|---|---|
| **Email** | Mas bajo | Mas alto | Cualquiera con lista de email |
| **Shadow Button** | Bajo | Alto | PMs en productos existentes |
| **404 / Coming Soon** | Bajo-Medio | Alto | Amazon, Kickstarter, startups |
