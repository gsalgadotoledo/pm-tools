# 33 - Experimento MVP: Los 7 Pasos

## Vision General

```
1. Problema/Solucion → 2. Identificar Supuestos → 3. Construir Hipotesis
→ 4. Criterio Minimo de Exito → 5. Elegir Tipo de MVP → 6. Ejecutar → 7. Iterar y Aprender
```

## Los 7 Pasos

| Paso | Que haces | Pregunta clave |
|---|---|---|
| **1. Problema/Solucion** | Definir el problema que resuelves y tu solucion propuesta | Que problema + que solucion? (deberia estar hecho de secciones anteriores) |
| **2. Identificar Supuestos** | Listar todo lo que tiene que salir bien para que esto tenga exito | Que estamos dando por sentado? Cual supuesto es el **mas riesgoso**? |
| **3. Construir Hipotesis** | Convertir supuestos en declaraciones testeables con criterios | "Creemos que [X] porque [Y], y lo podemos probar con [Z]" |
| **4. Criterio Minimo de Exito** | Trazar una linea — que = exito, que = fracaso | Si no definimos esto, no podemos saber si pasamos o fallamos |
| **5. Elegir Tipo de MVP** | Escoger el formato correcto de experimento | Depende de: tipo de feature, tamano de org, recursos |
| **6. Ejecutar** | Correr el experimento, obtener datos reales | Salir y probar con usuarios reales |
| **7. Iterar y Aprender** | Recopilar datos, evaluar: que funciono, que no, que cambiar | Si/No definitivo — es esto viable comparado con otras oportunidades? |

## Punto Clave

No necesitas **saber** que el problema existe y que esta es la mejor solucion. Para eso es el experimento. Solo necesitas un set problema/solucion **sobre la mesa** para probar.
