# 18 - Finding the Real Problem Behind Requests

## The PM Mindset

Don't just build what people ask for. Find the **real problem** behind the request.

> "Find a solution to a problem, instead of trying to fit a problem to a solution."

## The Towel Example

```
Friend in the rain: "Give me a towel"
    → Request: towel (symptom fix)
    → Real problem: they're in the rain
    → Real solution: get them out of the rain
```

## Two Questions for Every Request

1. **"Is this solving an actual problem?"**
2. **"If we do this exactly as asked, will it have unintended side effects?"**

## Example: Twitter Retweet Filter

| | |
|---|---|
| **Request** | Let users filter out retweets from timeline |
| **Seems reasonable?** | Yes — timeline is messy |
| **Unintended side effect** | 20-40% don't see retweets → fewer people retweet → Twitter loses signal on what's popular → hurts the core product |

## Example: E-commerce CMS

| | |
|---|---|
| **Request** | Marketing needs ability to post/remove quick messages on product pages |
| **Why?** | Merchandising told marketing to request it |
| **Why?** | Shorts page sizing/pictures were misleading → users confused → they leave |
| **Why?** | They wanted users to call support for clarification |
| **Real problem** | The page itself was misleading |
| **Real solution** | Redesign the page to be clear → no need for messages or support calls |

## The "Ask Why 3 Times" Technique

```
Someone asks you to build X
    → "Why do you need this?" → surface answer
    → "Why?" → closer to truth
    → "Why?" → real pain point revealed
```

Simple but **most people skip it.**

---

## Buzzwords

| Term | Definition |
|---|---|
| **Pain Point** | The real underlying problem a user is experiencing |
| **Symptom vs Problem** | The request is often a symptom; your job is to find the root cause |
| **Unintended Side Effects** | Negative consequences of building exactly what was asked |
| **The 3 Whys** | Technique: ask "why?" at least 3 times to get to the real problem |

## Frameworks

| Framework | What it is |
|---|---|
| **The 3 Whys** | Ask "why?" at least 3 times on any request to uncover the real pain point behind it |
