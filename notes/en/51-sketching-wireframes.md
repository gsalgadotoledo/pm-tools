# 51 - Sketching Wireframes: How to Start

## Start With Pen and Paper

Google, Microsoft, Facebook — everyone starts by sketching. Why?
- **Fast** — rapid task, don't overthink
- **Disposable** — easier to throw away and pivot
- **No attachment** — keeps you flexible
- **Free** — no software needed

## The Bulletproof Process

### Step 1: Draw a Browser
Immediately makes the blank page less overwhelming. Draw Chrome/Safari with tabs, URL bar, etc.

### Step 2: Add Logo + Navigation
Put logo in top corner, draw a nav bar (Home, etc.). Now it looks like something.

### Step 3: Answer "What is the point of this page?"
Write it out simply: *"Let users see video thumbnails so they can choose which to watch."*

### Step 4: List Functions
Write: *"Users should be able to:"*
- Function 1: Like videos → draw hearts on thumbnails
- Function 2: Search → draw search box
- Function 3: Paginate → draw "show 10/20/30 results"

### Step 5: Sketch Each Function Into the Wireframe

## If You Get Stuck

| Solution | How |
|---|---|
| **Browse major websites** | Play around with sites you use daily — find similar functions |
| **Find a comparable** | Think of a site that solves a similar problem |
| **Dribbble.com** | Designer showcase — browse layouts, buttons, forms for inspiration |

## The Most Important Rule

> **Function, not form.**

You are NOT the UX person. No one will judge your sketch for visual quality. Get the **function on the page** — someone else figures out the form later.
