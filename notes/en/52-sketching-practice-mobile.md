# 52 - Sketching Practice: Mobile Grocery App

## The Process in Action

### App idea: Mobile grocery delivery (order from nearby stores)

### Screen 1: Login / Splash Page

```
┌─────────────────┐
│   [Logo]         │
│                  │
│   App Name       │
│                  │
│ [Login Facebook] │
│ [Login Email]    │
│                  │
└─────────────────┘
        ↓ (after login)
```

### Screen 2: Main Screen

**Point of page**: Let users find a store and start picking items.

**Functions**: See items visually, see prices, search.

```
┌─────────────────┐
│ [Select Store ▼] │
│ ┌──────────────┐ │
│ │ Store Name   │ │
│ └──────────────┘ │
│ [🔍 Search...  ] │
│ ┌────┐ ┌────┐   │
│ │ 🍎 │ │ 🍌 │   │
│ │ $$  │ │ $$  │   │
│ ├────┤ ├────┤   │
│ │ 🍇 │ │ 🍊 │   │
│ │ $$  │ │ $$  │   │
│ └────┘ └────┘   │
│ [nav] [nav] [nav]│
└─────────────────┘
        ↓ (tap item)
```

### Screen 3: Detail Page

**Point of page**: Display item info so they can purchase.

**Functions**: See image, read description, select quantity, buy.

```
┌─────────────────┐
│                  │
│    [Big 🍎]      │
│                  │
│ ~~description~~  │
│ ~~text here~~~~  │
│                  │
│  Qty: [- 1 +]   │
│                  │
│   [BUY BUTTON]   │
│                  │
└─────────────────┘
```

## Key Reminders

- **Connect screens with arrows** — show the flow (left to right)
- **Label interactions** — write what button leads where
- **Start with easy stuff** — nav bars, login screens get juices flowing
- **Function, not form** — nobody judges your drawing skills
- **This is rapid** — supposed to be quick and disposable
