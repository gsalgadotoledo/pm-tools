# 70 - Side Projects for PM Experience

## When to Do a Side Project

When you have **zero relevant experience** at your current job to point to.

## What to Do

| Option | Effort | Description |
|---|---|---|
| **Redesign a product** | Low | Take a product you use daily, describe how you'd change it to solve user needs better (like designers do with UI redesigns) |
| **Blog post / write-up** | Low-Med | Document your process: problem identified → research → solution → wireframes |
| **Slide deck** | Medium | Present a feature proposal as if pitching to a product team |
| **Build a prototype** | Medium | Use tools (Figma, Balsamiq, POP) to create clickable wireframes/prototypes |
| **Full MVP** | High | Use no-code tools (Bubble, Webflow) to build and validate an idea |

## What to Document

1. **The user problem** you identified
2. **Your research** (competitors, user interviews, data)
3. **Your proposed solution** (wireframes, specs)
4. **Why this solution** over alternatives
5. **Metrics** you'd track to measure success

## Put It Somewhere Public

- Personal website/blog
- Medium article
- GitHub repo (like this one)
- Portfolio deck

> This is exactly what designers do to get hired — PMs can do the same with features and product thinking.
