# 33 - MVP Experiment: The 7 Steps

## Overview

```
1. Problem/Solution Set → 2. Identify Assumptions → 3. Build Hypotheses
→ 4. Minimum Criteria for Success → 5. Pick MVP Type → 6. Execute → 7. Iterate & Learn
```

## The 7 Steps

| Step | What you do | Key question |
|---|---|---|
| **1. Problem/Solution Set** | Define the problem you're solving and your proposed solution | What problem + what solution? (should be done already from earlier sections) |
| **2. Identify Assumptions** | List everything that has to go right for this to succeed | What are we taking for granted? Which assumption is the **riskiest**? |
| **3. Build Hypotheses** | Turn assumptions into testable statements with criteria | "We believe [X] because [Y], and we can test it by [Z]" |
| **4. Minimum Criteria for Success** | Draw a line in the sand — what = success, what = failure | If we don't define this, we can't know if we passed or failed |
| **5. Pick MVP Type** | Choose the right experiment format | Depends on: feature type, organization size, resources |
| **6. Execute** | Run the experiment, get real-life data | Get out there and test with real users |
| **7. Iterate & Learn** | Collect data, evaluate: what worked, what didn't, what to change | Hard yes/no — is this viable compared to other opportunities? |

## Key Insight

You don't need to **know** the problem exists and that this is the best solution. That's what the experiment is for. You just need a problem/solution set **on the table** to test.
