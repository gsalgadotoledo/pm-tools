# 29 - Feature Table for a Proposed Feature (Udemy Example)

## Two Uses of Feature Tables

| Use | When |
|---|---|
| **Post-mortem** (GoPro example) | Compare your existing product vs competitors — what to improve? |
| **Proposed feature** (this note) | Before building — what should we include based on what competitors already offer? |

## The Table: Group Discussion Feature

## Strategic Questions to Ask

1. Should we try to **beat them in all categories**?
2. Should we **deprioritize** because we can't win?
3. Should we just **ship the basics** so we can say we have it?
4. How far are we from being **the best** in this category?
5. **Should we even care** about this feature?

## Key Insight: Two Types of Feature Tables

```
Product-level table:  You vs competitors on EVERYTHING
                      → "Are we competitive overall?"

Feature-level table:  One specific feature across competitors
                      → "What should we build and how good does it need to be?"
```

Both are valuable. Use product-level for strategy, feature-level before building.
