# 50 - Wireframe vs Mockup vs Prototype

## The Fidelity Scale

```
Low Fidelity ←――――――――――――――――――――――――――――→ High Fidelity
  WIREFRAME          MOCKUP              PROTOTYPE
  Structure          Visuals             Usability
```

## Comparison

| | Wireframe | Mockup | Prototype |
|---|---|---|---|
| **Focus** | Structure, layout, organization | Colors, typography, style | Usability, interaction |
| **Fidelity** | Low | Medium | High |
| **Interactivity** | None | None (static) | Yes — clickable hotspots, basic gestures |
| **Who makes it** | PM + Designer | Designer | Designer + PM |
| **Analogy** | Blueprint | Painting | Working model |
| **Also called** | Skeleton | Static display | Interactive mockup |

## Don't Confuse Them

- **Wireframe** = structure → "Where does stuff go?"
- **Mockup** = visuals → "What does it look like?"
- **Prototype** = interaction → "How does it feel to use?"

## Tools by Phase

### Wireframing Tools
| Tool | Notes |
|---|---|
| **Balsamiq** | Most popular for low-fi, sketch-style, fun to use |
| **Axure** | Enterprise, collaborative, handles all 3 phases |
| **OmniGraffle** | Still used, clunky |
| **HotGloo** | Browser-based only |
| **POP** | Turn paper sketches into digital wireframes |

### Mockup Tools
| Tool | Notes |
|---|---|
| **Photoshop** | Most common, powerful but clunky for mockups |
| **Sketch** | Gaining popularity, faster than Photoshop |
| **Illustrator** | Vector-based, some designers prefer it |
| **Axure** | Has image library + templates for converting wireframes to mockups |
| **UXPin** | Wireframe-to-mockup workflow |

### Prototyping Tools
| Tool | Notes |
|---|---|
| **Keynote** | + Keynotopia templates — link slides together, load on phone/browser |
| **POP** | Add interactions to wireframe sketches |
| **Axure** | Full wireframe→mockup→prototype pipeline |
| **Proto.io** | Focused solely on mobile apps |
| **InVision** | Best for prototyping — import mockups, add multiple interaction layers |

---

> **See [Tools 2026 Update](tools-2026-update.md)** — InVision is dead, Adobe XD discontinued, Figma dominates all 3 phases. POP is dead. New AI tools (Figma Make, Uizard, Lovable) can generate prototypes from text prompts.
