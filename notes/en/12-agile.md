# 12 - Agile

## What is Agile?

**Lean applied to software development.** A project management framework for building software iteratively in small batches.

## How it Works

```
10 features on your list
        |
        v
Pick the 2-5 most important
        |
        v
Research -> Design -> Develop -> Release
        |
        v
Get user feedback FIRST
        |
        v
Then decide on the remaining features
```

## Lean vs Agile (Recap)

| | Lean | Agile |
|---|---|---|
| **What** | Philosophy | Software framework |
| **Scope** | Any business | Software development |
| **Core idea** | Don't waste resources | Build in small batches, validate, repeat |
| **Relationship** | Agile IS Lean applied to software |

## Key Principle

Don't build all 10 features. Build the top 2-5, release, get feedback, **then** decide what's next.

---

## Buzzwords

| Term | Definition |
|---|---|
| **Agile** | Iterative software development in small batches to avoid waste |
| **Iterative** | Building in repeated cycles of design → develop → release → feedback |
| **Kanban** | Framework within Agile (next note) |
| **Scrum** | Framework within Agile (next note) |
