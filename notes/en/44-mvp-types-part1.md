# 44 - MVP Types (Part 1): Email, Shadow Button, 404/Coming Soon

## The Principle

> Present something that **implies your product is real**. The extent to which you fake it determines which MVP type to use.

Validated learning requires users to **not know they're being tested**.

## MVP Types (Ordered: Most Fake → Least Fake)

### 1. Email MVP

| Aspect | Detail |
|---|---|
| **What** | Email a segment of users pitching a new feature/product as if it's real |
| **Resources needed** | Email client, user list, copywriting |
| **Difficulty** | Lowest |
| **Best for** | Established companies (have email list) AND early founders (gather target emails) |
| **Example** | AppSumo tests new products by emailing "come sign up" or even adding a buy button before the product exists |

### 2. Shadow Button MVP

| Aspect | Detail |
|---|---|
| **What** | Add a button in your product for a feature that doesn't exist yet. Track clicks. |
| **What happens on click** | Either: nothing (looks broken) or "Sorry, coming soon" message |
| **Resources needed** | Small dev effort to add button + tracking |
| **Best for** | PMs triaging nice-to-have features |
| **Example** | Startup deciding between login options (Email, Facebook, Twitter, Google, LinkedIn) — put fake buttons, see which ones people actually click |

### 3. 404 Page / Coming Soon Page

| Aspect | Detail |
|---|---|
| **What** | Link to a page that shows 404 or "Coming Soon — sign up for interest" |
| **Resources needed** | Landing page + signup form |
| **Best for** | Testing demand for entirely new products or categories |
| **Example: Amazon** | Uses 404/coming-soon pages **daily** to test demand for new categories |
| **Example: Oculus Rift** | Launched with just a rough prototype + a pre-order page = MVP |
| **Example: Kickstarter** | Pre-order pages are essentially coming-soon MVPs |

---

## Summary So Far

| MVP Type | Effort | Fakery Level | Who uses it |
|---|---|---|---|
| **Email** | Lowest | Highest | Anyone with an email list |
| **Shadow Button** | Low | High | PMs in existing products |
| **404 / Coming Soon** | Low-Medium | High | Amazon, Kickstarter, startups |
