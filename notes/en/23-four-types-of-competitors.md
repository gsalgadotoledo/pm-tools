# 23 - The Four Types of Competitors

## The Four Types

| Type | Same problem? | Same customer? | Priority |
|---|---|---|---|
| **Direct** | Yes | Yes | Tier 1 — highest concern |
| **Indirect** | Yes (different way) | Different/overlapping | Tier 2 |
| **Potential** | No | Yes/similar | Tier 3 |
| **Substitute** | Same core need | No | Tier 4 |

## Italian Restaurant Metaphor

| Type | Example |
|---|---|
| **Direct** | Italian restaurant across the street, same price, also sells tortellini |
| **Indirect** | Greek restaurant in another neighborhood (people confuse it for Italian) |
| **Potential** | Italian grocery store — doesn't serve meals but could add tables |
| **Substitute** | DiGiorno's frozen pizza — solves "hungry + want Italian" but totally different delivery |

## GoPro Example

| Type | Competitors | Why |
|---|---|---|
| **Direct** | Other action cameras (same form factor, same audience) | Same problem, same people |
| **Indirect** | Sony Cyber-Shot, Canon PowerShot | Can shoot action, but for kids' tennis match, not skydiving |
| | Vievu body camera | Same problem (small portable camera), but for police officers |
| **Potential** | Eyeshot 360 | WiFi camera for surveillance — same tech expertise, could pivot |
| **Substitute** | Opteka grip handle | Turns any camera into an action camera — different solution entirely |

## How to Organize Your List

```
TIER 1: Direct Competitors      ← most concerned, must be competitive
TIER 2: Indirect Competitors    ← don't lose too many customers to them
TIER 3: Potential Competitors   ← keep in periphery, make sure they can't easily do what you do
TIER 4: Substitute Competitors  ← make sure you're a viable alternative
```

Replace "Known/Unknown" categories with these 4 tiers in your spreadsheet.

## Buzzwords

| Term | Definition |
|---|---|
| **Direct Competitor** | Same problem, same customer — users make a conscious choice between you |
| **Indirect Competitor** | Same problem, different way or different customer group |
| **Potential Competitor** | Same customers but different problem — could pivot into your space |
| **Substitute Competitor** | Solves the same core need in a completely different way |
| **Peripheral Competitor** | Another name for Potential — keep them in your periphery |
| **Competitive Landscape** | The full picture of all competitors organized by type and priority |
