# 58 - AARRR Pirate Metrics Framework

## What is AARRR?

A 5-step metrics framework by **Dave McClure** (500 Startups). Popular in Silicon Valley, especially for SaaS and startups seeking investment.

## The 5 Steps (Funnel)

```
Acquisition → Activation → Retention → Referral → Revenue
    A             A            R           R          R
```

| Step | What it means | Example metric |
|---|---|---|
| **Acquisition** | User arrived (visited site, downloaded app) | New visitors/month, app downloads |
| **Activation** | User signed up and did a key action | % downloads that create account + add profile pic |
| **Retention** | User comes back repeatedly | % users active month-over-month |
| **Referral** | User refers others (happy enough to share) | Invites sent/user, referral conversion rate |
| **Revenue** | User generates money | Revenue/user, subscription conversion, ad revenue/user |

## How Each Step Feeds the Next

```
Lots acquired → Some activate → Fewer retain → Even fewer refer → Revenue from the best
```

Optimize metrics at each step to maximize the bottom of the funnel.

## Retention Optimization Examples

- Push notification if user hasn't logged in for 1-2 weeks
- Email drip campaigns (weekly → biweekly → monthly)

## Referral Optimization Examples

- Dropbox: invite a friend → get free storage
- Uber: share a code → both get a free ride

## HEART vs AARRR

| | HEART | AARRR |
|---|---|---|
| **Creator** | Kerry Rodden (Google) | Dave McClure (500 Startups) |
| **Focus** | Product experience + happiness | Growth funnel + revenue |
| **Includes happiness?** | Yes (H) | No (implied in Referral) |
| **Includes engagement?** | Yes (E) | No (implied in Retention) |
| **Includes task success?** | Yes (T) | No |
| **Best for** | PMs at established companies | Startups, SaaS, seeking investment |
