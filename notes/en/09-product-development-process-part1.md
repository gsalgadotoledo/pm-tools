# 09 - Product Development Process (Part 1)

## The 7 Phases

```
Conceive -> Plan -> Develop -> Iterate -> Launch -> Steady State -> Maintain/Kill
[--- this note ---]                       [--- next note ---]
```

## Phase 1: Conceive

- Collect **user problems**
- **Brainstorm** solutions
- Identify **focus areas**
- Biggest source of ideas: **employees within the company**

## Phase 2: Plan

- **Market research** on the ideas
- Evaluate the **business case** — will this make money?
- **Customer interviews** — do people actually have this problem?
- **Roadmap** — what to build, how long, feature milestones

## Phase 3: Develop

- Create **timelines**
- Write **user stories** and **specs**
- Get **estimations** from development on specific features
- Requirements should be **set and locked** until MVP validation

## Phase 4: Iterate

- Finish the **MVP** (Minimum Viable Product) — the early prototype
- Get **early feedback** from users
- **Test assumptions** from the original idea
- Don't wait until fully done — test as early as possible
- Use **Alpha** and **Beta** programs to validate direction

---

## Buzzwords

| Term | Definition |
|---|---|
| **Product Development Process** | The 7 phases a product goes through from idea to end-of-life |
| **MVP** | Minimum Viable Product — simplest version to validate with users |
| **Business Case** | The justification for building something — will it make money/impact? |
| **Customer Interviews** | Talking to potential users to validate if a problem exists |
| **Alpha** | Internal test version, before beta |
| **Beta** | Pre-release version tested by a limited group of real users |
